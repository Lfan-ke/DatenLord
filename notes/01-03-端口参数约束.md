# 模块的泛型、端口、参数及约束

<!-- By Leo Cheng -->

在这里不使用`泛型`这个表述，使用`参数化`来代指，一个语言自己的方言习惯...

## 参数示例

|参数类型|关键字|说明|示例|
|:--:|:--:|:--:|:--:|
|数值参数|Integer|整数常量|Integer depth = 16|
|类型参数|type t|数据类型| ... |
|数值类型参数|numeric type n|编译时常量| ... |

```bluespec
module mkModuleName#(参数)(端口，默认Empty，即：没有端口); // 没有端口也得必须写，哪怕写个空括号
endmodule

// 非参数化：只能做4位加法
module mkAdder4(Adder4IFC);

// 参数化：可以做任意位宽加法（numeric type n 经接口传入，不写进 #()）
module mkAdder(AdderIFC#(n));
```

**数值参数示例**：

```bluespec
// 带数值参数的模块，比如初始化特定次数的counter
module mkCounter#(Integer max_val)(Empty);

  Reg#(Bit#(32)) count <- mkReg(0);

  rule rl_count;
    if (count < fromInteger(max_val - 1)) // 需要 fromInteger 转换整数到电路
      count <= count + 1;
    else
      count <= 0;
  endrule

endmodule

// 实例化（接口类型在左，值参数在右侧 () 里，不用 #）
Empty c1 <- mkCounter(100);
Empty c2 <- mkCounter(256);
```

**类型参数示例**：

```bluespec
// 通用 FIFO 接口
interface FIFO#(type t);
  method Action enq(t x);
  method Action deq();
  method t first();
  method Bool notEmpty();
  method Bool notFull();
endinterface

// 通用寄存器接口
interface Reg#(type t);
  method Action _write(t x);
  method t _read();
endinterface

// 实例化不同类型的 FIFO
FIFO#(Bit#(8)) fifo_byte <- mkFIFO;
FIFO#(int) fifo_int <- mkFIFO;
FIFO#(MyStruct) fifo_struct <- mkFIFO;
```

**数值类型参数**：

```bluespec
// 位宽参数化：numeric type n 经【接口】传入，不写进 #()
interface Sized#(numeric type n);
  method Bit#(n) value;
endinterface

module mkSized(Sized#(n))
  provisos (Add#(1, n, m));  // n+1 = m，用于进位扩展

  Bit#(n) a = 0;
  Bit#(n) b = 0;
  Bit#(m) sum = zeroExtend(a) + zeroExtend(b);   // 扩展到 n+1 位
  method Bit#(n) value = truncate(sum);
endmodule

// 实例化：位宽由接口类型决定
Sized#(8)  s8  <- mkSized;
Sized#(16) s16 <- mkSized;
Sized#(32) s32 <- mkSized;
```

**混合使用示例**：

```bluespec
// 多个 numeric type 参数也都经【接口】传入
interface Mem#(numeric type addr_sz, numeric type data_sz);
  method Action        write(Bit#(addr_sz) a, Bit#(data_sz) d);
  method Bit#(data_sz) read(Bit#(addr_sz) a);
endinterface

module mkMemory(Mem#(addr_sz, data_sz));
  Vector#(TExp#(addr_sz), Reg#(Bit#(data_sz))) mem <- replicateM(mkReg(0));
  method Action write(Bit#(addr_sz) a, Bit#(data_sz) d); mem[a] <= d; endmethod
  method Bit#(data_sz) read(Bit#(addr_sz) a) = mem[a];
endmodule
```

**数值`vs.`数值类型参数**：

```bluespec
Integer      - 是一个数字，一个值，用于循环，编译期常量
numeric type - 是一个类型，编译时类型，定义其他类型的大小，如 Bit#(n)

for (Integer i = 0; i < depth; i = i + 1) - 对于编译期常量是合法的
provisos (Add#(1, n, m));                 - 在类型层面定义 m= n+1
Bit#(n) x;                                - 类型层面 n 的位宽定义
Vector#(n, t) v;                          - 类型层面 n 的位宽定义

// 对于数字转换为电路：
fromInteger(max_val - 1)                  // 数字可运行时计算
// 对于类型层面的常量，同样的数转换电路需要：
fromInteger(valueOf(n))                   // valueOf 转换为数字

// provisos，承诺，是对类型参数的约束，告诉编译器这个类型必须支持哪些操作
provisos (Bits#(t, sz));
//                 ↑
// 这是一个类型变量，代表"t 的位宽"，习惯`sz`(size)，可习惯命名为其他的，如：emm
// 假设 t = Bit#(8)，则 sz = 8
// 假设 t = Bit#(32)，则 sz = 32
// 假设 t = MyStruct，sz 是所有字段位宽之和

module mkPackModule#(t initVal)(Empty)   // 用值参数 #(t initVal) 绑定类型 t
    provisos (Bits#(t, sz));  // sz = t 的位宽

    Reg#(t) data <- mkReg(initVal);
    Reg#(Bit#(sz)) pk <- mkReg(0);   // 注意 packed 是保留字，改名 pk

    rule r;
        pk <= pack(data);  // t → Bit#(sz)
    endrule
endmodule
```

**数值世界和类型世界**：

```
┌─────────────────────────────────────────────────────────────┐
│                    编译时 - 类型世界                         │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  numeric type n = 8                                 │    │
│  │  TAdd#(n,1) = 9                                     │    │
│  │  TLog#(16) = 4                                      │    │
│  └─────────────────────────────────────────────────────┘    │
│                         │                                   │
│                         │ valueOf(n)                        │
│                         ▼                                   │
├─────────────────────────────────────────────────────────────┤
│                      运行时 - 值世界                         │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  Integer n_val = 8                                  │    │
│  │  Bit#(32) n_bits = fromInteger(valueOf(n))          │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

**常见 Provisos 速查表**

| Proviso | 提供的操作 | 硬件含义 | 类似 Rust Trait |
|:---------:|:-----------:|:----------:|:-----------------:|
| `Bits#(t, n)` | `pack(t) → Bit#(n)`, `unpack(Bit#(n)) → t` | 类型可映射为位向量 | `Bitwise` + 固定大小 |
| `Eq#(t)` | `==`, `!=` | 组合逻辑比较器 | `PartialEq` |
| `Ord#(t)` | `<`, `<=`, `>`, `>=`, `min`, `max` | 大小比较器 | `Ord` |
| `Arith#(t)` | `+`, `-`, `*`, `/`, `%` | 运算电路 | `Num` |
| `Bitwise#(t)` | `&`, `\|`, `^`, `~`, `<<`, `>>` | 位运算电路 | `BitAnd`, `BitOr` 等 |
| `Literal#(t)` | `fromInteger(i)`, `inLiteralRange(x,i)` | 常量值注入 | `From<i64>` |
| `Bounded#(t)` | `minBound`, `maxBound` | 类型取值范围 | `Bounded` |
| `FShow#(t)` | `fshow(t) → Fmt` | 仿真打印 | `Display` |

自动推导：

```bluespec
module mkM#(t v)(Empty);     // 值参数 #(t v) 绑定类型 t
    Reg#(t) r <- mkReg(v);   // → 需要 Bits#(t, sz)
    // 若用到 ==（需 Eq#(t)）、+（需 Arith#(t)），编译器会要求补对应 provisos
endmodule
// 等价于显式声明：
module mkM#(t v)(Empty)
    provisos (Bits#(t, sz), Eq#(t), Arith#(t));

// --- 但是推荐自己手动声明，毕竟有些是有绑定关系的：

// Ord（bsc 中 Ord 不以 Eq 为超类，用 == 需另写 Eq#(t)）
provisos (Ord#(t));

// Arith 仅隐含 Literal（不隐含 Bitwise）
provisos (Arith#(t));  // 自动提供 +, -, *, /, 以及 fromInteger
```

使用示例：

```bluespec
// 排序模块的约束
module mkSorter(SorterIFC#(n, t))   // n、t 经接口传入，不写进 #()
  provisos (
    Bits#(t, t_sz),       // 可存储
    Ord#(t),              // 可比较
    Eq#(t),               // 可相等
    Bounded#(t),          // 有最大/最小值
    Literal#(t)           // 可使用字面量
  );

  // 现在可以：
  // - 存储 t 到寄存器
  // - 比较 t 值（<, >）
  // - 判断相等（==, !=）
  // - 使用 maxBound 作为标记值
  // - 使用整数常量 0, 1 等
endmodule
```

## 端口类型

**端口类型选项**：

| 端口类型 | 语法 | 说明 | 示例 |
|:---:|:---:|:---:|:---:|
| 无端口 | `Empty` 或 `()` | 模块无任何外部接口 | `module mkTest(Empty);` |
| 自定义接口 | `接口名` | 模块提供特定方法 | `module mkCounter(Counter_IFC);` |
| 参数化接口 | `接口名#(type)` | 接口带类型参数 | `module mkFIFO(FIFO_IFC#(t));` |
| 元组接口 | `Tuple2#(ifc1, ifc2)` | 多接口组合（用 Tuple 类型，**不是** `(a,b)` 端口列表语法） | `module mkDual(Tuple2#(Reg#(t), Reg#(t)));` |

**接口使用示例**：

```bluespec
// 定义接口
interface Counter_IFC;
    method Action increment;
    method Bit#(32) read_value;
endinterface

// 模块实现接口
module mkCounter(Counter_IFC);
    Reg#(Bit#(32)) value <- mkReg(0);

    method Action increment;
        value <= value + 1;
    endmethod

    method Bit#(32) read_value;
        return value;
    endmethod
endmodule

// 参数化接口
interface FIFO_IFC#(type t);
    method Action enq(t x);
    method Action deq();
    method t first();
    method Bool notEmpty();
endinterface
```

**元组端口示例**：

```bluespec
// 返回多个独立接口：模块接口类型写成 Tuple2#(...)，返回用 tuple2(...)
module mkPair(Tuple2#(Reg#(Bit#(8)), Reg#(Bit#(8))));
    Reg#(Bit#(8)) reg_a <- mkReg(0);
    Reg#(Bit#(8)) reg_b <- mkReg(0);
    return tuple2(reg_a, reg_b);  // 返回元组
endmodule

// 使用
match {.ra, .rb} <- mkPair;
rule r; ra <= ra + 1; endrule
```

## 约束补充

**类型级/编译时算术**：

| 操作 | 含义 | 示例 |
|:---:|:---:|:---:|
| `TAdd#(n, m)` | n + m | `TAdd#(8, 1) = 9` |
| `TSub#(n, m)` | n − m | `TSub#(8, 1) = 7` |
| `TMul#(n, m)` | n × m | `TMul#(8, 2) = 16` |
| `TLog#(n)` | ceil(log₂(n)) | `TLog#(32) = 5` |
| `TExp#(n)` | 2ⁿ | `TExp#(3) = 8` |
| `TMin#(n, m)` | min(n, m) | `TMin#(8, 16) = 8` |
| `TMax#(n, m)` | max(n, m) | `TMax#(8, 16) = 16` |
| `TDiv#(n, m)` | ceil(n / m)（类型级整除，向上取整） | `TDiv#(10, 3) = 4` |

> BSC 只有以上类型级算术；**没有** `TMod` / `TCmp`（取模、比较类型级不存在）。注意 `TDiv` 是**向上取整**（`TDiv#(10,3)=4`，常用于算 BRAM 行数等）。

使用示例：

```bluespec
// 添加大小关系约束
module mkExample#(Bit#(n) sample)(Empty)   // 用值参数 Bit#(n) 绑定 numeric type n
  provisos (Add#(n, 1, m));                // m = n + 1
  // 其他大小关系约束的写法（按需选用，彼此互斥不会同时出现）：
  //   Mul#(n, 2, m)   // m = n * 2
  //   Log#(n, m)      // m = ceil(log2(n))；类型相等用同一变量表达，无 Eq 数值 proviso
```

**转换函数**：

| 函数 | 方向 | 说明 |
|:------:|:------:|:------:|
| `valueOf(n)` | `numeric type` → `Integer` | 类型世界 → 值世界 |
| `fromInteger(i)` | `Integer` → `Bit#(n)` | 值 → 位向量 |
| `pack(x)` | 任意 `Bits` 类型 → `Bit#(n)` | 序列化 |
| `unpack(x)` | `Bit#(n)` → 任意 `Bits` 类型 | 反序列化 |

**常用一览**：

| 概念 | 语法 | 说明 |
|:------:|:------:|:------:|
| 模块声明 | `module mkName#(值参数)(接口);` | **只有值参数进 `#()`**，接口在后面的 () 中 |
| 无端口 | `Empty` 或 `()` | 必须写，不能省略 |
| 数值参数(值) | `#(Integer x)` / `#(Bit#(8) y)` | 编译期常量/值，值世界，进 `#()` |
| 类型参数 | `module mk(Ifc#(t))` | **type 经接口传入**，或由值参数类型推断；不写进 `#()` |
| 数值类型参数 | `module mk(Ifc#(n))` | **numeric type 经接口传入**（或值参数 `Bit#(n)` 绑定）；不写进 `#()` |
| 类型约束 | `provisos (Bits#(t, sz))` | 约束类型能力 |
| 类型→值 | `valueOf(n)` | numeric type → Integer |
| 值→位 | `fromInteger(i)` | Integer → Bit#(n) |
| 打包 | `pack(x)` | 任意 Bits → Bit#(n) |
| 解包 | `unpack(x)` | Bit#(n) → 任意 Bits |
| 编译时加法 | `TAdd#(n, m)` | n + m |
| 编译时乘法 | `TMul#(n, m)` | n × m |
| 编译时对数 | `TLog#(n)` | ceil(log₂(n)) |
| 编译时指数 | `TExp#(n)` | 2ⁿ |
| 带复位寄存器 | `mkReg(x)` | 有复位逻辑 |
| 无复位寄存器 | `mkRegU()` | 无复位，更小，需先写后读 |
| 异步复位 | `mkRegA(x)` | 异步复位 |
| 向量初始化 | `replicateM(mkReg(0))` | 批量初始化 |
| 接口定义 | `interface IFC#(参数);` | 接口也可参数化 |
