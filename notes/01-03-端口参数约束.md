# 模块的泛型、端口、参数及约束

<!-- By Leo Cheng -->

在这里不使用`泛型`这个表述，使用`参数化`来代指，一个语言自己的方言习惯...

## 参数示例

|参数类型|关键字|说明|示例|
|:--:|:--:|:--:|:--:|
|数值参数|Integer|整数常量|Integer depth = 16|
|类型参数|type t|数据类型|type t|
|数值类型参数|numeric type n|编译时常量|numeric type n|

```bluespec
module mkModuleName#(参数)(端口，默认Empty，即：没有端口); // 没有端口也得必须写，哪怕写个空括号
endmodule

// 非参数化：只能做4位加法
module mkAdder4(Adder4IFC);

// 参数化：可以做任意位宽加法
module mkAdder#(numeric type n)(AdderIFC#(n));
```

**数值参数示例**：

```bluespec
// 带数值参数的模块，比如初始化特定次数的counter
module mkCounter#(Integer max_val)(Empty);

  Reg#(Bit#(32)) count <- mkReg(0);

  rule rl_count;
    if (count < fromInteger(max_val - 1)) // 需要 fromInteger 转换整数到电路
      count <= count + 1;
    else
      count <= 0;
  endrule

endmodule

// 实例化
mkCounter#(100) c1 <- mkCounter;
mkCounter#(256) c2 <- mkCounter;
```

**类型参数示例**：

```bluespec
// 通用 FIFO 接口
interface FIFO#(type t);
  method Action enq(t x);
  method Action deq();
  method t first();
  method Bool notEmpty();
  method Bool notFull();
endinterface

// 通用寄存器接口
interface Reg#(type t);
  method Action _write(t x);
  method t _read();
endinterface

// 实例化不同类型的 FIFO
FIFO#(Bit#(8)) fifo_byte <- mkFIFO;
FIFO#(int) fifo_int <- mkFIFO;
FIFO#(MyStruct) fifo_struct <- mkFIFO;
```

**数值类型参数**：

```bluespec
// 位宽参数化的加法器
module mkAdder#(numeric type n)(Empty)
  // provisos - 用于类型约束
  provisos (Add#(1, n, m));  // n+1 = m，用于进位

  Bit#(n) a = 0;
  Bit#(n) b = 0;

  // 扩展到 n+1 位
  Bit#(m) sum = zeroExtend(a) + zeroExtend(b);

endmodule

// 实例化不同位宽
mkAdder#(8) adder8 <- mkAdder;  // 实例化端口Empty可省略()
mkAdder#(16) adder16 <- mkAdder;
mkAdder#(32) adder32 <- mkAdder;
```

**混合使用示例**：

```bluespec
// 同时使用多种参数
module mkMemory#(
    numeric type addr_sz,    // 地址位宽
    numeric type data_sz,    // 数据位宽
    type t                   // 存储类型
)(Empty)
  provisos (Bits#(t, data_sz));  // t 必须能表示为 data_sz 位

  Vector#(TExp#(addr_sz), Reg#(t)) mem <- replicateM(mkRegU);

  // 地址类型
  typedef Bit#(addr_sz) Addr;
  typedef Bit#(data_sz) Data;

  // 读写逻辑...
endmodule
```

**数值`vs.`数值类型参数**：

```bluespec
Integer      - 是一个数字，一个值，用于循环，编译期常量
numeric type - 是一个类型，编译时类型，定义其他类型的大小，如 Bit#(n)

for (Integer i = 0; i < depth; i = i + 1) - 对于编译期常量是合法的
provisos (Add#(1, n, m));                 - 在类型层面定义 m= n+1
Bit#(n) x;                                - 类型层面 n 的位宽定义
Vector#(n, t) v;                          - 类型层面 n 的位宽定义

// 对于数字转换为电路：
fromInteger(max_val - 1)                  // 数字可运行时计算
// 对于类型层面的常量，同样的数转换电路需要：
fromInteger(valueOf(n))                   // valueOf 转换为数字

// provisos，承诺，是对类型参数的约束，告诉编译器这个类型必须支持哪些操作
provisos (Bits#(t, sz));
//                 ↑
// 这是一个类型变量，代表"t 的位宽"，习惯`sz`(size)，可习惯命名为其他的，如：emm
// 假设 t = Bit#(8)，则 sz = 8
// 假设 t = Bit#(32)，则 sz = 32
// 假设 t = MyStruct，sz 是所有字段位宽之和

module PackModule#(type t)(Empty)
    provisos (Bits#(t, any_name));  // 任意名称都可以

    Reg#(t) data <- mkRegU();
    Reg#(Bit#(any_name)) packed <- mkReg(0);  // 使用该名称

    // Integer bit_width = valueOf(sz);       // 获取位宽数值 ...

    rule r;
        packed <= pack(data);  // t → Bit#(any_name)
    endrule
endmodule
```

**数值世界和类型世界**：

```
┌─────────────────────────────────────────────────────────────┐
│                    编译时 - 类型世界                         │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  numeric type n = 8                                 │    │
│  │  TAdd#(n,1) = 9                                     │    │
│  │  TLog#(16) = 4                                      │    │
│  └─────────────────────────────────────────────────────┘    │
│                         │                                   │
│                         │ valueOf(n)                        │
│                         ▼                                   │
├─────────────────────────────────────────────────────────────┤
│                      运行时 - 值世界                         │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  Integer n_val = 8                                  │    │
│  │  Bit#(32) n_bits = fromInteger(valueOf(n))          │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

**常见 Provisos 速查表**

| Proviso | 提供的操作 | 硬件含义 | 类似 Rust Trait |
|:---------:|:-----------:|:----------:|:-----------------:|
| `Bits#(t, n)` | `pack(t) → Bit#(n)`, `unpack(Bit#(n)) → t` | 类型可映射为位向量 | `Bitwise` + 固定大小 |
| `Eq#(t)` | `==`, `!=` | 组合逻辑比较器 | `PartialEq` |
| `Ord#(t)` | `<`, `<=`, `>`, `>=`, `min`, `max` | 大小比较器 | `Ord` |
| `Arith#(t)` | `+`, `-`, `*`, `/`, `%` | 运算电路 | `Num` |
| `Bitwise#(t)` | `&`, `|`, `^`, `~`, `<<`, `>>` | 位运算电路 | `BitAnd`, `BitOr` 等 |
| `Literal#(t)` | `fromInteger(i)`, `fromString(s)` | 常量值注入 | `From<i64>` |
| `Bounded#(t)` | `minBound`, `maxBound` | 类型取值范围 | `Bounded` |
| `FShow#(t)` | `fshow(t) → String` | 仿真打印 | `Display` |

自动推导：

```bluespec
module M#(type t)(Empty);
    Reg#(t) r <- mkRegU();   // → 需要 Bits#(t, sz)
    if (x == y) ...          // → 需要 Eq#(t)
    let sum = x + y;         // → 需要 Arith#(t)
endmodule
// 等价于显式声明：
module M#(type t)(Empty)
    provisos (Bits#(t, sz), Eq#(t), Arith#(t));

// --- 但是推荐自己手动声明，毕竟有些是有绑定关系的：

// Ord 隐含 Eq（能排序必然能判等）
provisos (Ord#(t));  // 自动提供 Eq#(t)

// Arith 隐含 Bitwise 和 Literal
provisos (Arith#(t));  // 自动提供 +, -, *, /, 以及 fromInteger
```

使用示例：

```bluespec
// 排序模块的约束
module mkSorter#(numeric type n, type t)(SorterIFC#(n, t))
  provisos (
    Bits#(t, t_sz),       // 可存储
    Ord#(t),              // 可比较
    Eq#(t),               // 可相等
    Bounded#(t),          // 有最大/最小值
    Literal#(t)           // 可使用字面量
  );

  // 现在可以：
  // - 存储 t 到寄存器
  // - 比较 t 值（<, >）
  // - 判断相等（==, !=）
  // - 使用 maxBound 作为标记值
  // - 使用整数常量 0, 1 等
endmodule
```

## 端口类型

**端口类型选项**：

| 端口类型 | 语法 | 说明 | 示例 |
|:---:|:---:|:---:|:---:|
| 无端口 | `Empty` 或 `()` | 模块无任何外部接口 | `module mkTest(Empty);` |
| 自定义接口 | `接口名` | 模块提供特定方法 | `module mkCounter(Counter_IFC);` |
| 参数化接口 | `接口名#(type)` | 接口带类型参数 | `module mkFIFO(FIFO_IFC#(t));` |
| 元组接口 | `(类型1, 类型2, ...)` | 多接口组合 | `module mkDual((Reg#(t) a, Reg#(t) b));` |

**接口使用示例**：

```bluespec
// 定义接口
interface Counter_IFC;
    method Action increment;
    method Bit#(32) read_value;
endinterface

// 模块实现接口
module mkCounter(Counter_IFC);
    Reg#(Bit#(32)) value <- mkReg(0);

    method Action increment;
        value <= value + 1;
    endmethod

    method Bit#(32) read_value;
        return value;
    endmethod
endmodule

// 参数化接口
interface FIFO_IFC#(type t);
    method Action enq(t x);
    method Action deq();
    method t first();
    method Bool notEmpty();
endinterface
```

**元组端口示例**：

```bluespec
// 返回多个独立接口
module mkPair(Empty);
    Reg#(Bit#(8)) reg_a <- mkReg(0);
    Reg#(Bit#(8)) reg_b <- mkReg(0);
    return (reg_a, reg_b);  // 返回元组
endmodule

// 使用
match {.ra, .rb} <- mkPair;
rule r; ra <= ra + 1; endrule
```

## 约束补充

**类型级/编译时算术**：

| 操作 | 含义 | 示例 |
|:---:|:---:|:---:|
| `TAdd#(n, m)` | n + m | `TAdd#(8, 1) = 9` |
| `TMul#(n, m)` | n × m | `TMul#(8, 2) = 16` |
| `TLog#(n)` | ceil(log₂(n)) | `TLog#(32) = 5` |
| `TExp#(n)` | 2ⁿ | `TExp#(3) = 8` |
| `TMin#(n, m)` | min(n, m) | `TMin#(8, 16) = 8` |
| `TMax#(n, m)` | max(n, m) | `TMax#(8, 16) = 16` |
| `TDiv#(n, m)` | n / m（整数除法） | `TDiv#(10, 3) = 3` |
| `TMod#(n, m)` | n % m（取模） | `TMod#(10, 3) = 1` |
| `TCmp#(n, m)` | 比较，返回 Bool 类型 | `TCmp#(8, 16) = False` |

使用示例：

```bluespec
// 添加大小关系约束
module mkExample#(numeric type n, numeric type m)(Empty)
  provisos (
    Add#(n, 1, m),        // m = n + 1
    Mul#(n, 2, m),        // m = n * 2
    Log#(n, m),           // m = ceil(log2(n))
    Eq#(n, m)             // n == m
  );
```

**转换函数**：

| 函数 | 方向 | 说明 |
|:------:|:------:|:------:|
| `valueOf(n)` | `numeric type` → `Integer` | 类型世界 → 值世界 |
| `fromInteger(i)` | `Integer` → `Bit#(n)` | 值 → 位向量 |
| `pack(x)` | 任意 `Bits` 类型 → `Bit#(n)` | 序列化 |
| `unpack(x)` | `Bit#(n)` → 任意 `Bits` 类型 | 反序列化 |

**常用一览**：

| 概念 | 语法 | 说明 |
|:------:|:------:|:------:|
| 模块声明 | `module mkName#(参数)(端口);` | 参数在 #() 中，端口在 () 中 |
| 无端口 | `Empty` 或 `()` | 必须写，不能省略 |
| 数值参数 | `#(Integer x)` | 编译期常量，值世界，支持=默认值 |
| 类型参数 | `#(type t)` | 类型抽象 |
| 数值类型参数 | `#(numeric type n)` | 编译时常量，类型世界 |
| 类型约束 | `provisos (Bits#(t, sz))` | 约束类型能力 |
| 类型→值 | `valueOf(n)` | numeric type → Integer |
| 值→位 | `fromInteger(i)` | Integer → Bit#(n) |
| 打包 | `pack(x)` | 任意 Bits → Bit#(n) |
| 解包 | `unpack(x)` | Bit#(n) → 任意 Bits |
| 编译时加法 | `TAdd#(n, m)` | n + m |
| 编译时乘法 | `TMul#(n, m)` | n × m |
| 编译时对数 | `TLog#(n)` | ceil(log₂(n)) |
| 编译时指数 | `TExp#(n)` | 2ⁿ |
| 带复位寄存器 | `mkReg(x)` | 有复位逻辑 |
| 无复位寄存器 | `mkRegU()` | 无复位，更小，需先写后读 |
| 异步复位 | `mkRegA(x)` | 异步复位 |
| 向量初始化 | `replicateM(mkReg(0))` | 批量初始化 |
| 接口定义 | `interface IFC#(参数);` | 接口也可参数化 |
