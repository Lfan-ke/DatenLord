# 标准库用法 (八)：随机 / 校验 / 编码

> 可跑：`execs/13-09-01-RandCrc`。

## LFSR（伪随机 / 计数）

```bsv
import LFSR::*;
LFSR#(Bit#(8)) r <- mkLFSR_8;     // 还有 _4/_16/_32、mkPolyLFSR(taps)、mkFeedLFSR(mask)、mkRCounter
r.seed(8'h1);   r.value;   r.next;   // 注意：value 与 next 不能在同一 rule（要分拍）
```

## CRC

```bsv
import CRC::*;
CRC#(16) c <- mkCRC_CCITT;        // 还有 mkCRC16/mkCRC32、通用 mkCRC#(poly,init,finalXor,reflD,reflR)
c.add(8'h31);  c.add(8'h32);      // ★ 每个 add 要在不同 rule（方法每 rule 只能调一次，否则 G0004）
c.result;   c.complete;           // result 读，complete 读并复位
```

## Gray（跨时钟域安全编码）

```bsv
import Gray::*;
Gray#(6) g = grayEncode(6'd6);    // 6=0b110 → gray 0b101=5（相邻只变 1 位）
Bit#(6)  v = grayDecode(g);       // 5 → 6
grayIncr(g); grayDecr(g);
// import GrayCounter::*; mkGrayCounter#(init, dClk, dRstN)：计数并同步到 dClk
```

## Randomizable

```bsv
import Randomizable::*;
Randomize#(Bit#(16)) rnd <- mkConstrainedRandomizer(0, 99);   // 或 mkGenericRandomizer(全范围)
rule init;    rnd.cntrl.init;  endrule        // 先 init 一次
rule consume; let x <- rnd.next; endrule       // 注意 use 是保留字，rule 别叫 use
```

## 实测（execs/13-09-01）

```
lfsr=1  lfsr=8e  lfsr=47        <- 8 位 LFSR 序列
crc=5bce                         <- CRC-16-CCITT("123")
gray(6)=5 decode=6               <- Gray 编/解码
```

> 通用坑:**一个 method 每个 rule 只能调一次**(如 `crc.add`、`lfsr.value+next`)，多次要分到不同周期，否则 `G0004 conflict in parallel`。
