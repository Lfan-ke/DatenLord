# 规则的并发和并行

BSV采用一种别样的思路，另外一个视角的抽象，使用原子事务来描述电路逻辑

## 原子事务

```bluespec
rule r_swap;     // x y 旧值互换
    x <= y;      // 同时执行
    y <= x;      // 不需要临时变量
endrule
```

同一规则内写同一寄存器两次会直接编译报错，不同规则的规则间冲突使用调度注解来处理冲突

规则可以使用优先级，执行顺序等概念来消减冲突，保证原子性和可预见性

> 专有名词：
>
> CAN_FIRE  : rule 块满足自身守卫条件，或者压根没有条件
>
> WILL_FIRE : 在 CAN 的基础上，还满足调度的规则，被选中 <- 真正的实际执行

```bluespec
Reg#(int) x <- mkReg(0);

rule r1 (x < 10);   // CAN_FIRE 在 x<10 时为真
    x <= x + 1;
endrule

rule r2 (x > 5);    // CAN_FIRE 在 x>5 时为真
    x <= x + 2;
endrule

// 当 x 同时满足两个条件，两个规则的 CAN_FIRE 同时为真，它们都写 x，存在冲突
// 为了避免编译器默认乱选，需要手动来注解优先级，比如：
(* descending_urgency = "r1, r2" *)     // 当然，得写在规则前面，，，但为了上下文...
// 这样子在冲突的时候，就会优先执行 r1 而不选中 r2 因为他们随时随地冲突，所以只会执行其一
```

高级用法

```bluespec
Reg#(int) x <- mkReg(0);
Reg#(Bool) valid <- mkReg(False);

rule producer;
    x <= x + 1;
    valid <= True;
endrule

// producer会/必须比consumer先被调度
rule consumer (valid && WILL_FIRE(producer));
    $display("Consuming: %d", x);
    valid <= False;
endrule
```

## 规则注解

以 `(*)` 或 `{‑*}` 的形式写在 rule 之前，告诉编译器如何处理规则之间的冲突和优先级

`(*)` - 单元素注解，应用于紧随其后的一个规则、模块、方法等

`{‑*}` - 多元素作用域注解，应用于一个代码块内的所有相关元素 - 作用域注解会"向下传递"

`{-*}`写文件开头就是全局注解... 其中，优先级覆盖：

|优先级|注解位置|示例|
|:--:|:--:|:--:|
|最高|规则上的 (*)|(* descending_urgency = "A,B" *) rule A;|
|中等|内层作用域 {‑*}|嵌套在内部的作用域|
|最低|外层作用域 {‑*}|最外层的作用域|

其中，常见的注解：

| 注解 | 语法 | 作用范围 | 说明 | 使用示例 |
|:------:|:------:|:----------:|:------:|:------:|
| `descending_urgency` | `"r1, r2, r3"` | 规则 | 指定优先级，左高右低 | `(* descending_urgency = "r_high, r_low" *)` |
| `preempts` | `"r1, r2"` | 规则 | r1 触发时强制禁用 r2 | `(* preempts = "r_int, r_norm" *)` |
| `mutually_exclusive` | `"r1, r2"` | 规则 | 声明规则互斥 | `(* mutually_exclusive = "rA, rB" *)` |
| `execution_order` | `"r1, r2"` | 规则 | 强制串行顺序 | `(* execution_order = "r_first, r_second" *)` |
| `synthesize` | - | 模块 | 生成独立 Verilog 模块 | `(* synthesize *) module mkTop(...);` |
| `no_implicit_conditions` | - | 规则 | 移除隐式条件（危险） | `(* no_implicit_conditions *) rule r;` |
| `fire_when_enabled` | - | 规则 | 强制执行（打破依赖） | `(* fire_when_enabled *) rule r;` |
| `always_ready` | - | 方法 | RDY 始终为真 | `(* always_ready *) method Action m;` |
| `always_enabled` | - | 方法 | EN 始终为真 | `(* always_enabled *) method int m;` |
| `options` | `"opt1, opt2"` | 模块/规则 | 编译器选项 | `(* options = "synthesize, area_opt" *)` |
| `doc` | `"text"` | 任意 | 文档字符串 | `(* doc = "This module does X" *)` |
| `parameter` | `"name value"` | 模块 | 覆盖模块参数 | `(* parameter = "width 32" *)` |
| `prefix` | `"str"` | 模块 | 生成 Verilog 方法名前缀 | `(* prefix = "my_" *)` |
| `clock_family` | `"clk"` | 模块/规则 | 时钟域归属 | `(* clock_family = "slow_clk" *)` |
| `reset_family` | `"rst"` | 模块/规则 | 复位域归属 | `(* reset_family = "soft_rst" *)` |
| `port` | `"name"` | 接口方法 | 端口重命名 | `(* port = "data_in" *)` |
| `ready` | `"sig"` | 方法 | 自定义 RDY 信号名 | `(* ready = "my_rdy" *)` |
| `enable` | `"sig"` | 方法 | 自定义 EN 信号名 | `(* enable = "my_en" *)` |
| `result` | `"sig"` | 方法 | 自定义返回值信号名 | `(* result = "my_result" *)` |
| `CLK` | `"clk"` | 模块 | 重命名时钟端口 | `(* CLK = "sys_clk" *)` |
| `RST_N` | `"rst_n"` | 模块 | 重命名复位端口 | `(* RST_N = "sys_rst_n" *)` |
| `noinline` | - | 函数 | 禁止内联 | `(* noinline *) function int f;` |
| `inline` | - | 函数 | 强制内联 | `(* inline *) function int f;` |
| `deprecate` | `"msg"` | 模块/方法 | 标记为废弃 | `(* deprecate = "Use newAPI instead" *)` |
| `scan` | - | 模块 | 控制扫描链插入 | `(* scan *) module mkModule(...);` |
| `resource` | `"name"` | 规则/模块 | 指定硬件资源类型 | `(* resource = "multiplier" *)` |
| `conserve` | - | 规则 | 能量/面积优化提示 | `(* conserve *) rule r_low_power;` |
| `enable_warnings` | - | 模块 | 启用特定警告 | `(* enable_warnings *) module mkM(...);` |
| `no_warn` | - | 模块 | 关闭特定警告 | `(* no_warn *) module mkM(...);` |

单行使用方法：

```bluespec
// 应用于单个规则
(* descending_urgency = "r1, r2" *)
rule r1;
    x <= x + 1;
endrule

// 应用于模块
(* synthesize *)
module mkAdder(Empty);
    // ...
endmodule

// 应用于方法
interface FIFO_IFC;
    (* always_ready *)
    method Bit#(32) first();

    (* always_enabled *)
    method Action enq(Bit#(32) x);
endinterface
```

多行使用示例：

```
{‑* descending_urgency = "B, A" *-}    // ← 完整的开括号 - 是的，这一行是完整的开括号
    rule B; ... endrule
    rule A; ... endrule
*-}                                    // ← 完整的闭括号，如果不闭合，则会影响下面所有
```

全部混在一起的例子：

```bluespec
module MultiAnnotationExample(Empty);
    Reg#(int) counter <- mkReg(0);
    Reg#(int) data <- mkReg(0);
    Reg#(State) state <- mkReg(IDLE);
    Reg#(Bool) error_flag <- mkReg(False);

    // ============================================
    // 外层作用域：全局调度策略
    // ============================================
    {‑*
        descending_urgency = "error_handler, normal_op"
        preempts = "reset_all, normal_op"
    *-}

        // 错误处理规则（最高优先级）
        rule error_handler (error_flag);
            $display("ERROR: handling error");
            state <= ERROR_STATE;
            counter <= 0;
        endrule

        // 正常操作规则（被 error_handler 抢占）
        rule normal_op (state == ACTIVE);
            $display("normal_op: counter=%d", counter);
            counter <= counter + 1;
            if (counter == 100) state <= IDLE;
        endrule

        // 复位规则（抢占 normal_op）
        rule reset_all (reset_signal);
            $display("RESET: resetting all");
            state <= IDLE;
            counter <= 0;
            error_flag <= False;
        endrule

        // ============================================
        // 内层作用域：覆盖部分规则的互斥关系
        // ============================================
        {‑*
            mutually_exclusive = "state_idle, state_active"
            descending_urgency = "state_active, state_idle"  // 覆盖外层
        *-}

            // 空闲状态规则（与 state_active 互斥）
            rule state_idle (state == IDLE);
                $display("state_idle: waiting for start");
                if (start_signal) state <= ACTIVE;
            endrule

            // 活跃状态规则（与 state_idle 互斥）
            rule state_active (state == ACTIVE);
                $display("state_active: processing");
                data <= data + 1;
                if (data == 255) state <= IDLE;
            endrule

        *-}  // 内层结束

        // 规则级注解覆盖外层
        (* preempts = "debug_rule, normal_op" *)  // debug 抢占 normal_op
        rule debug_rule (debug_mode);
            $display("DEBUG: normal_op disabled");
        endrule

    *-}  // 外层结束

    // 完全独立的规则（无任何注解）
    rule independent (True);
        $display("independent: always runs");
    endrule

endmodule
```
