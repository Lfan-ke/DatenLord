# 标准库用法 (三)：寄存器变体

> 可跑：`execs/13-04-01-RegVariants`。多数变体接口是 `Reg#(t)`，差别在调度/复位/行为；唯 `mkBypassReg` 例外，接口是 `WReg#(t)`（比 Reg 多一个 `bypass` 方法）。

```bsv
import ConfigReg::*; import DReg::*; import BypassReg::*;

Reg#(t) a <- mkReg(v);        // 同步复位到 v；read < write（读旧值）
Reg#(t) u <- mkRegU;          // 无复位（省面积，承诺先写后读）
Reg#(t) b <- mkRegA(v);       // 异步复位到 v
Reg#(t) c <- mkConfigReg(v);  // 同 mkReg 硬件，但 read/write 无调度约束（打破读写冲突，常用作 CSR）
Reg#(t) d <- mkDReg(v);       // 写入只保持 1 拍，之后自动回默认 v（one-shot 脉冲/valid）
WReg#(t) y <- mkBypassReg(v); // ★ 返回 WReg#(t)（不是 Reg#(t)）：bypass(x) 同拍组合前递给 _read
Reg#(t) rv <- mkRevertingVirtualReg(v);  // 纯调度用虚寄存器，强制 read<write 排序，写值忽略
```

| 模块 | 复位 | 调度 / 行为 |
|:---:|:---:|:---:|
| `mkReg` | 同步 | `read < write` |
| `mkRegU` | 无 | 同上 |
| `mkRegA` | **异步** | 同上 |
| `mkConfigReg` | 同步 | **read/write 无约束**（读恒旧值） |
| `mkDReg` | 同步 | 写后保持 **1 拍**，再自动回默认 |
| `mkBypassReg` | 同步 | `bypass` 组合前递 |
| `mkRevertingVirtualReg` | — | 仅排序用，写被忽略 |

## 实测：DReg 的 one-shot（execs/13-04-01）

```
cyc=2 ... (第2拍发起写 99)
cyc=3  plain=99  dreg=99  cfg=99     <- 写生效
cyc=4  plain=99  dreg=0   cfg=99     <- dreg 自动回 0！plain/cfg 保持
```
→ `mkDReg` 适合做"只有效一拍"的脉冲/valid 信号；`mkConfigReg` 适合让多 rule 不因读写冲突而被串行化。
