# 标准库用法 (四)：计数器

> 可跑：`execs/13-05-01-Counters`。

## Cntrs：并发计数器（CReg/EHR 式）

```bsv
import Cntrs::*;
Count#(UInt#(8)) c <- mkCount(0);   // 关键：incr 与 decr 可在【同一周期】不同 rule 触发
rule a (...); c.incr(5); endrule    // 这两条同拍 → 净 +3
rule b (...); c.decr(2); endrule
// 方法：incr/decr/update/_write/_read；调度 _read < update < (incr,decr) < _write

// UCount：位宽按 maxValue 自动选，带比较
UCount uc <- mkUCount(0, 100);      // mkUCount#(Integer init, Integer maxValue)
... uc.incr(1); uc.isEqual(3); uc.isLessThan(10); uc.isGreaterThan(50); ...
```

## Counter（Base1，Verilog 原语封装）

```bsv
import Counter::*;
Counter#(8) k <- mkCounter(0);
k.up; k.down; k.inc(v); k.dec(v); k.value; k.setC(v); k.clear;
```

## 实测（execs/13-05-01）

```
cyc=1  count=3   ...      <- incr(5)+decr(2) 同拍 → 净 +3
cyc=2  count=6
cyc=3  count=9  ucount=3(==3?1)   <- UCount.isEqual(3) 命中
```
→ 多 rule 同周期改一个计数器(如性能计数、信用计数)就用 `Cntrs.Count`；普通用 `Counter`。
