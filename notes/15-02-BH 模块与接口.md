# BH 模块·接口·寄存器

> 接 15-01。本篇讲 BH 怎么写接口、模块、状态。寄存器写是 **`:=`**，provisos 是前置上下文 `(…) =>`。

## 接口

```haskell
-- 声明：interface 名 类型变量 = 方法 :: 类型 ; …
interface FIFO a =
    enq   :: a -> Action
    deq   :: Action
    first :: a
    clear :: Action

interface Reg a =            -- 内置寄存器接口
    _write :: a -> Action
    _read  :: a
```

- **子接口**就是类型为另一接口的方法；接口元组 `type GetPut a = (Get a, Put a)`。
- **构造接口值**两种写法：
  ```haskell
  interface FIFO            -- 具名字段式
     enq x = …
     deq   = …
  interface (g, p)          -- 元组式（返回多个子接口）
  ```

## 模块

```haskell
-- 签名：具体 Module，或多态模块单子 (IsModule m c) => … -> m Ifc
mkAccum :: Module Accum
mkGCD   :: (IsModule m c) => m (ArithIO (Bit 32))

mkAccum = module
    acc :: Reg (Bit 16)        -- 先类型签名
    acc <- mkReg 0             -- 再用 <- 实例化（monadic bind）
    -- 也可合并： acc :: Reg (Bit 16) <- mkReg 0
    let dbl = acc + acc        -- let（无 in）绑普通值
    rules
      …                        -- 可选规则段（见 15-03）
    interface                  -- 返回的接口
      add x = acc := acc + zeroExtend x
      total = acc
```

- `module` 本质是 `Module` 单子里的 `do`；可 `return ifc` 或末尾写 `interface …`。
- **实例化**用 `<-`；裸表达式语句按副作用执行。
- `IsModule m c`：`mkReg` 等原语是多态的 `(IsModule m c, Bits a sa) => a -> m (Reg a)`；`liftModule $ module …` 把具体 `Module` 抬进多态单子。

## 寄存器 & 状态

```haskell
r :: Reg (Bit 8) <- mkReg 0      -- 同步复位
u :: Reg (Bit 8) <- mkRegU       -- 无复位
r := r + 1                       -- 写：r := v  等价 r._write (r._read + 1)
x = r                            -- 读：裸 r 自动 ._read；显式 r._read；asReg r 抑制自动读
```

> 寄存器调度同 BSV：`read < write`（同拍读到旧值）。其它寄存器变体（ConfigReg/DReg…）见 13-01。

## provisos（前置上下文）

BH **没有 `provisos` 关键字**，类型约束写成签名最前面的上下文：

```haskell
mkConfigReg :: (IsModule m c, Bits a sa) => a -> m (Reg a)
(++)        :: (Add m n mn) => Bit m -> Bit n -> Bit mn
```

等价于 BSV 的 `provisos (Bits#(a,sa))`、`provisos (Add#(m,n,mn))`，只是挪到了 `=>` 前。

## 隐式方法条件

```haskell
-- 方法体后加 when：该方法仅在条件成立时就绪（生成 RDY）
enq x = f.enq x      when f.notFull
first =  f.first     when f.notEmpty
```

等价 BSV 的 `method … if (cond)`。

## 完整示例（15-02-01）

```haskell
package Accum (Accum(..), mkAccum) where
interface Accum =
    add   :: Bit 8 -> Action
    total :: Bit 16
mkAccum :: Module Accum
mkAccum = module
    acc :: Reg (Bit 16) <- mkReg 0
    interface
      add x = acc := acc + zeroExtend x
      total = acc
```
