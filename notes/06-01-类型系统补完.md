## 基本类型

| 类型 | 说明 | 综合 |
|:------:|:------:|:------:|
| `Bit#(n)` | n 位位向量 | ✅ |
| `Int#(n)` | n 位有符号整数 | ✅ |
| `UInt#(n)` | n 位无符号整数 | ✅ |
| `Bool` | 布尔 (True/False) | ✅ |
| `Integer` | 无限精度整数 | ❌ 仅编译时 |
| `String` | 字符串 | ❌ 仅仿真 |

## 复合类型

| 类型 | 语法 | 常用 deriving（按需，可单独 derive） |
|:------:|:------:|:------:|
| 枚举 | `typedef enum {A,B,C} T` | `Bits, Eq` |
| 结构体 | `typedef struct {t1 f1; t2 f2;} T` | `Bits, Eq` |
| 带标签联合体 | `typedef union tagged {void A; t B;} T` | `Bits, Eq` |

## 容器类型

| 类型 | 导入 | 说明 |
|:------:|:------:|:------:|
| `Vector#(n, t)` | `import Vector::*` | 固定大小数组 |
| `List#(t)` | `import List::*` | 链表（仿真用） |
| `Tuple2#(t1,t2)` ~ `Tuple8#...` | 内置 | 元组 |
| `Maybe#(t)` | 内置 | 可选值（tagged union） |

## 参数化类型参数

| 参数 | 用途 | 示例 |
|:------:|:------:|:------:|
| `type t` | 类型参数 | `FIFO#(t)` |
| `numeric type n` | 数值类型参数 | `Bit#(n)` |

## 函数类型

| 类型 | 说明 |
|:------:|:------:|
| `function t f(...)` | 纯函数，无副作用 |

综合为组合逻辑

## 类型类约束

> `Provisos`

| 约束 | 提供的方法 |
|:------:|:-----------:|
| `Bits#(t, sz)` | `pack`, `unpack` |
| `Eq#(t)` | `==`, `!=` |
| `Ord#(t)` | `<`, `<=`, `>`, `>=` |
| `Bounded#(t)` | `minBound`, `maxBound` |
| `Arith#(t)` | `+`, `-`, `*`, `/` |
| `Literal#(t)` | `fromInteger` |
| `FShow#(t)` | `fshow` |

## 其他相关补充

> 支持 `let a = 8'd233;` 使用`let`进行类型自动推断（位宽要放得下：233 需 ≥8 位，`6'd233` 会 T0132 溢出）
