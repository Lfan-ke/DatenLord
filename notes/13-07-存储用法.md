# 标准库用法 (六)：存储 RegFile / BRAM

> 可跑：`execs/13-07-01-Storage`。

## RegFile（多读口/单写口，组合读）

```bsv
import RegFile::*;
RegFile#(Bit#(4), Bit#(8)) rf <- mkRegFileFull;   // 16×8；或 mkRegFile(lo,hi)
rf.upd(3, 8'hAA);            // 写
let x = rf.sub(3);          // 读（同拍可读；sub < upd）
// mkRegFileWCF: upd/sub 无冲突；mkRegFileLoad("hex",lo,hi): 文件初始化(多仿真用)
```

## BRAM（Server 风格，带延迟）

```bsv
import BRAM::*; import DefaultValue::*;
BRAM_Configure cfg = defaultValue;          // memorySize/latency/loadFormat/outFIFODepth/allowWriteResponseBypass
cfg.memorySize = 1024;
BRAM2Port#(Bit#(10), Bit#(32)) mem <- mkBRAM2Server(cfg);   // 双口；也有 mkBRAM1Server / *BE 字节使能 / mkSyncBRAM2Server

// 写
mem.portA.request.put(BRAMRequest{write:True,  responseOnWrite:False, address:a, datain:d});
// 读：先发请求，延迟后取响应
mem.portB.request.put(BRAMRequest{write:False, responseOnWrite:False, address:a, datain:?});
let d <- mem.portB.response.get;
```

> 底层 `BRAMCore`(Base2) 是 `BRAM_PORT` 的 put/read，无 FIFO，更贴硬件。
> 大 FIFO 用 `mkSizedBRAMFIFO`(见 13-02)。

## 实测（execs/13-07-01）

```
RegFile[3]=aa [5]=bb     <- RegFile 当拍读
BRAM[3]=aa

```
