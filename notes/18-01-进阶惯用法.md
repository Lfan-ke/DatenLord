# 进阶惯用法

> 参考用 BSV 写的真实 RISC-V 核：[Piccolo](https://github.com/bluespec/Piccolo)(3级流水)、[Flute](https://github.com/bluespec/Flute)(5级)、[SHAKTI](https://shakti.org.in) SoC。下面提炼它们反复用到的工程惯用法，**每段都本地编译/实跑验证**(见 `execs/18-01-01-Pipeline`)。仅作参考与补充。

## 1. 流水线 = 规则 + 级间 FIFO

核流水线把每一级写成一个 rule，级之间用 FIFO 解耦；FIFO **选型**决定时序：

| 级间 FIFO | 时序 | 用途 |
|---|---|---|
| `mkBypassFIFOF` | 0 拍(组合穿过) | 输入注入、需要同拍前递 |
| `mkPipelineFIFOF` | 1 拍(寄存器) | 普通流水寄存 |
| `mkFIFOF`(深≥2) | 缓冲 | 吸收背压/不等速 |

```bsv
FIFOF#(Op)      s1 <- mkBypassFIFOF;
FIFOF#(Bit#(8)) s2 <- mkPipelineFIFOF;
rule exec; let op = s1.first; s1.deq; … s2.enq(r); endrule   // 一级一 rule
rule wb;   let r  = s2.first; s2.deq; … endrule
```

## 2. CReg/EHR —— 多 rule 同拍并发状态

> EHR(Ephemeral History Register) 在 BSV 里就是 **CReg / `Cntrs`**(见 03-01/12-01)。核里 PC、scoreboard、性能计数、epoch 都靠它让多条 rule 在**同一周期**有序地读改。

```bsv
import Cntrs::*;
Count#(UInt#(16)) cycles <- mkCount(0);   // 性能计数器
rule tick; cycles.incr(1); endrule        // 这条与其它用 cycles 的 rule 可同拍
// scoreboard：Vector#(32, Reg#(Bool)) busy <- replicateM(mkReg(False));
//   要并发置/清同一项用 CReg：Reg#(Bool) e[] <- mkCReg(2,False); 取 e[0]/e[1] 两口（mkCReg 返回数组）
```

## 3. tagged union 载荷 + `case matches`

指令/流水载荷/总线事务普遍用 tagged union 表达"几选一 + 携带数据"：

```bsv
typedef union tagged { Bit#(8) Compute; void Bubble; } Op deriving (Bits, Eq);
case (op) matches
   tagged Compute .v: s2.enq(v * 2);
   tagged Bubble:     noAction;
endcase
```

## 4. epoch / flush（分支冲刷）

分支误预测时用 epoch 标记"换代"，丢弃旧代在途的包：

```bsv
Reg#(Bit#(1)) epoch <- mkConfigReg(0);          // CSR/epoch 类用 ConfigReg（读写无调度约束）
// 取指打上 epoch；执行级比对，不符则丢：
rule exec; if (pkt.epoch == epoch) … else noAction (* 丢弃 *); endrule
// 误预测：epoch <= ~epoch; 重定向 PC
```

## 5. 访存/缓存接口 = Client/Server + mkConnection

核与 cache/总线之间用 `Client#(Req,Rsp)`/`Server#(Req,Rsp)`，一行 `mkConnection` 接通（见 04-01/04-02）。请求/响应是整笔事务，天然解耦。

## 6. Maybe 包 valid/data

可选值(寄存器是否有效、转发是否命中)用 `Maybe#(t)`：`tagged Valid v` / `tagged Invalid`，配 `fromMaybe`/`isValid`。

## 7. SoC 互联：AXI4 fabric（bsc-contrib）

真实 SoC(SHAKTI/Flute 的外围)用 AMBA fabric。bsc-contrib 的 `AMBA_Fabrics`(AXI4/AXI4-Lite/AXI4-Stream + Adapters)即此用途；加路径 `-p +:/usr/local/bsc-contrib/Libraries/AMBA_Fabrics`(见 16-01)。
