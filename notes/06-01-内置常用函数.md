# BSV 内置函数概览

---

## 类型转换函数

| 函数 | 签名 | 说明 |
|:------:|:------:|:------:|
| `pack` | `pack(x: t) → Bit#(n)` | 将任意 `Bits` 类型打包成位向量 |
| `unpack` | `unpack(b: Bit#(n)) → t` | 将位向量解包成原类型 |
| `zeroExtend` | `zeroExtend(x: Bit#(m)) → Bit#(n)` | 零扩展（m < n），高位补 0 |
| `signExtend` | `signExtend(x: Int#(m)) → Int#(n)` | 符号扩展，高位补符号位 |
| `extend` | `extend(x: t) → t'` | 自动选择 zeroExtend 或 signExtend |
| `truncate` | `truncate(x: Bit#(m)) → Bit#(n)` | 截取低 n 位（m > n） |
| `truncateLSB` | `truncateLSB(x: Bit#(m)) → Bit#(n)` | 截取高 n 位（去掉低位） |
| `fromInteger` | `fromInteger(i: Integer) → t` | 整数常量转具体位宽类型 |

---

## 数值类型与值转换

| 函数 | 签名 | 说明 |
|:------:|:------:|:------:|
| `valueOf` | `valueOf(numeric type n) → Integer` | 将数值类型转为 Integer（编译时） |
| `sizeOf` | `sizeOf(type t) → Integer` | 返回类型 t 的位宽（编译时） |
| `isClocked` | `isClocked(expr) → Bool` | 检查表达式是否在时钟域中 |

---

## 位向量操作函数

| 函数 | 签名 | 说明 |
|:------:|:------:|:------:|
| `countOnes` | `countOnes(x: Bit#(n)) → Bit#(TLog#(n+1))` | 统计 1 的个数 |
| `countZeros` | `countZeros(x: Bit#(n)) → Bit#(TLog#(n+1))` | 统计 0 的个数 |
| `lsb` | `lsb(x: Bit#(n)) → Bit#(1)` | 取最低位 |
| `msb` | `msb(x: Bit#(n)) → Bit#(1)` | 取最高位 |
| `reverseBits` | `reverseBits(x: Bit#(n)) → Bit#(n)` | 位反转 |
| `signBit` | `signBit(x: Int#(n)) → Bit#(1)` | 取符号位 |

---

## 算术辅助函数

| 函数 | 签名 | 说明 |
|:------:|:------:|:------:|
| `abs` | `abs(x: Int#(n)) → Int#(n)` | 绝对值 |
| `min` | `min(x: t, y: t) → t` | 最小值（需要 `Ord`） |
| `max` | `max(x: t, y: t) → t` | 最大值（需要 `Ord`） |
| `clog2` | `clog2(x: Integer) → Integer` | 计算 ceil(log2(x))（编译时） |

## 常用类型类方法

| 类型类 | 提供的方法 |
|:------:|:-----------:|
| `Bits#(t, sz)` | `pack`, `unpack` |
| `Eq#(t)` | `==`, `!=` |
| `Ord#(t)` | `<`, `<=`, `>`, `>=`, `min`, `max` |
| `Arith#(t)` | `+`, `-`, `*`, `/`, `%`, `abs` |
| `Bitwise#(t)` | `&`, `|`, `^`, `~`, `<<`, `>>` |
| `Bounded#(t)` | `minBound`, `maxBound` |
| `Literal#(t)` | `fromInteger` |
| `FShow#(t)` | `fshow` |
