# 结构化状态机

<!-- lec06 -->

> StmtFSM, Structured Finite State Machine - 结构化状态机

传统的状态机是`每个状态一个规则`的手工状态机编码方式，容易出错，`SFSM`将抽象提升为类似软件编程的顺序、条件、循环描述方式

## 模型对比

**传统的状态机模型**：

```bluespec
typedef enum {
    S0, S1, S2, S3, S4
} State deriving (Bits, Eq);

module mkFSM_Manual(Empty);
  Reg#(State) state <- mkReg(S0);
  Reg#(int) counter <- mkReg(0);

  rule r0 (state == S0);
    $display("Step 0");
    state <= S1;
  endrule

  rule r1 (state == S1);
    $display("Step 1");
    state <= S2;
  endrule

  rule r2 (state == S2);
    $display("Step 2");
    if (counter < 5) begin
      counter <= counter + 1;
      state <= S1;  // 循环
    end else begin
      state <= S3;
    end
  endrule

  rule r3 (state == S3);
    $display("Done");
    $finish;
  endrule
endmodule
```

**结构化状态机模型**：

```bluespec
import StmtFSM::*;

module mkFSM_StmtFSM(Empty);
  mkAutoFSM(
    seq
      $display("Step 0");
      $display("Step 1");
      for (i <= 0; i < 5; i <= i + 1)
        $display("Loop iteration %d", i);
      $display("Done");
      $finish;
    endseq
  );
endmodule
```
