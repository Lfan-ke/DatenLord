# 标准库用法 (一)：FIFO 家族

> 13-01 是总索引；13-02 起是各包的**使用示例**。本篇:FIFO 家族。可跑工程见 `execs/13-02-01-FifoFamily`。

## FIFO / FIFOF

```bsv
import FIFO::*; import FIFOF::*;

FIFO#(Bit#(8))  f  <- mkFIFO;    // 深2；方法带隐式条件(满/空自动 stall)
FIFOF#(Bit#(8)) ff <- mkFIFOF;   // 多 notFull/notEmpty 两个查询

// 典型生产者-消费者
rule prod (i < 5 && ff.notFull);  ff.enq(i*10); i <= i+1;        endrule
rule cons (ff.notEmpty);          $display("%0d", ff.first); ff.deq; endrule
```

| 构造子 | 深度/语义 |
|:---:|:---:|
| `mkFIFO`/`mkFIFOF` | 深 2 |
| `mkFIFO1`/`mkFIFOF1` | 深 1 |
| `mkSizedFIFO(n)`/`mkSizedFIFOF(n)` | 深 n |
| `mkLFIFO`/`mkLFIFOF` | 深1 loopy，满时可同拍 deq+enq(**deq 先**) |
| `mkUGFIFOF` / `mkGFIFOF#(Bool ugenq, Bool ugdeq)` | 去隐式条件(自己查 notFull/notEmpty) |

## SpecialFIFOs —— 1 元素，同拍但方向不同

```bsv
import SpecialFIFOs::*;
FIFO#(t) p <- mkPipelineFIFO;   // 1拍；满时可 deq、或同拍 deq+enq（deq 先）
FIFO#(t) b <- mkBypassFIFO;     // 0拍；空时可 enq、或同拍 enq+deq（enq 先，组合通路）
FIFOF#(t) d <- mkDFIFOF(dflt);  // deq/first 无隐式条件，空时 first 返回 dflt
```

> 口诀:**Pipeline=deq先(寄存器/1拍)、Bypass=enq先(组合/0拍)**。核流水线级间常用(见 18-01)。
> 坑:special FIFO 的同拍 enq+deq 在 `StmtFSM` 单 action 里易触发 **G0033**(组合自环);用独立 rule 更稳。

## 其它

```bsv
import BRAMFIFO::*;
FIFO#(t) s <- mkSizedBRAMFIFO(64);   // BRAM 背书的大深度 FIFO

import FIFOLevel::*;

// FIFOCountIfc 暴露 count
```
