# 类型类系统

<!-- lec 08 -->

> `Typeclasses`

类型类定义了一组重载操作，不同类型可以以不同方式实现这些操作，类似于其他语言的`Trait`或`Interface`...

<!-- 弱弱的补充：`OOP` 是 面向对象编程 `Object-Oriented Programming` 的缩写 -->

## 基本使用示例

```bluespec
// Eq 类型类：定义相等比较
typeclass Eq#(type t);
  function Bool ==(t a, t b);
  function Bool !=(t a, t b);
endtypeclass

// 为 Int 类型 实现 Eq 类型类
instance Eq#(Int);
  function Bool ==(Int a, Int b) = ...;
  function Bool !=(Int a, Int b) = ...;
endinstance

// 现在可以比较 Int 类型的变量
if (x == y) ...

// 同样的，我们可以为结构体以及其他类型实现 Eq 类型类
instance Eq#(struct xxx);
  function Bool ==(struct xxx a, struct xxx b) = ...;
  function Bool !=(struct xxx a, struct xxx b) = ...;
endinstance

/* --- --- | --- | --- --- */

// 函数使用 provisos 约束
function t max(t a, t b) provisos (Ord#(t));
  return (a < b) ? b : a;
endfunction

Int result1 = max(x, y);  // 使用函数，综合是组合逻辑
```

类型类系统提供了强大的抽象能力，使得代码更具可重用性和灵活性。通过定义类型类，我们可以编写泛型代码，适用于多种类型，而不需要重复实现相同的逻辑。

## 内置类型类

### Bits

最基础的类型类，用于类型与位向量之间的转换。

```bluespec
typeclass Bits#(type t, numeric type sz);
  function Bit#(sz) pack(t x);
  function t unpack(Bit#(sz) x);
endtypeclass

// 使用示例
Bit#(32) pk = pack(my_struct);       // 结构体 → 位向量（packed 是保留字，用 pk）
MyStruct unpacked = unpack(bits);    // 位向量 → 结构体
```

支持自动派生，例如：

```bluespec
typedef enum { IDLE, RUN, DONE } State
  deriving (Bits, Eq);

typedef struct {
  Bit#(8) addr;
  Bit#(32) data;
} Packet deriving (Bits);
```

### Eq

相等比较类型类，提供相等和不相等操作。

```bluespec
typeclass Eq#(type t);
  function Bool ==(t a, t b);
  function Bool !=(t a, t b);
endtypeclass

// 使用示例
if (x == y) ...
if (x != y) ...
```

### Ord

排序比较类型类，提供大小比较和极值操作（bsc 中 Ord 不以 Eq 为超类，用 `==` 需另声明 `Eq#(t)`）。

```bluespec
typeclass Ord#(type t);
  function Bool <(t a, t b);
  function Bool <=(t a, t b);
  function Bool >(t a, t b);
  function Bool >=(t a, t b);
  function t min(t a, t b);
  function t max(t a, t b);
endtypeclass

// 使用示例
if (x < y) ...
let smaller = min(x, y);
```

### Bounded

有界类型类，提供类型的最小值和最大值。

```bluespec
typeclass Bounded#(type t);
  function t minBound;
  function t maxBound;
endtypeclass

// 使用示例
Bit#(8) max = maxBound;   // 255
Int#(8) min = minBound;   // -128
```

### Literal

字面量转换类型类，将整数字面量转换为具体类型。

```bluespec
typeclass Literal#(type t);
  function t fromInteger(Integer x);
endtypeclass

// 使用示例
Bit#(8) x = 42;        // 自动调用 fromInteger(42)
Int#(16) y = -100;     // 自动调用 fromInteger(-100)
```

### Arith

算术运算类型类，提供基本算术操作。

```bluespec
typeclass Arith#(type t);
  function t +(t a, t b);
  function t -(t a, t b);
  function t *(t a, t b);
  function t /(t a, t b);
  function t %(t a, t b);
  function t negate(t a);
  function t abs(t a);
  function t signum(t a);
endtypeclass

// 使用示例
let sum = a + b;
let product = x * y;
let absolute = abs(x);
```

### Bitwise

位运算类型类，提供按位操作和移位。

```bluespec
typeclass Bitwise#(type t);
  function t ~(t a);
  function t &(t a, t b);
  function t |(t a, t b);
  function t ^(t a, t b);
  function t <<(t a, Bit#(n) b);
  function t >>(t a, Bit#(n) b);
  function Bit#(1) msb(t a);
  function Bit#(1) lsb(t a);
endtypeclass

// 使用示例
Bit#(8) result = a & b;
Bit#(8) shifted = a << 2;
Bit#(1) high = msb(a);
```

### BitExtend

位宽扩展与截断类型类。

```bluespec
typeclass BitExtend#(type s, type d);
  function d extend(s x);
  function d zeroExtend(s x);
  function d signExtend(s x);
  function s truncate(d x);
endtypeclass
// 注：truncateLSB 不在本类，是 PreludeBSV 的独立函数

// 使用示例
Bit#(16) b16 = zeroExtend(b8);
Int#(16) i16 = signExtend(i8);
Bit#(8) b8 = truncate(b16);
```

### FShow

格式化输出类型类，用于仿真调试打印。

```bluespec
typeclass FShow#(type t);
  function Fmt fshow(t x);
endtypeclass

// 使用示例（fshow 返回 Fmt，直接传给 $display，不要用 %s）
$display(fshow(my_value));
```

### DefaultValue

默认值类型类，返回类型的默认值。

```bluespec
typeclass DefaultValue#(type t);
  function t defaultValue;
endtypeclass

// 使用示例（reg 是保留字，用 r）
Reg#(t) r <- mkReg(defaultValue);
```

### Connectable

接口连接类型类，用于将两个接口连接在一起。

```bluespec
typeclass Connectable#(type a, type b);
  module mkConnection#(a x, b y)(Empty);
endtypeclass

// 使用示例
mkConnection(get_ifc, put_ifc);
mkConnection(client, server);
```

### Add

编译时加法约束。

```bluespec
typeclass Add#(numeric type a, numeric type b, numeric type c);
  // 约束：a + b = c
endtypeclass

// 使用示例
provisos (Add#(n, 1, m));  // m = n + 1
```

### Mul

编译时乘法约束。

```bluespec
typeclass Mul#(numeric type a, numeric type b, numeric type c);
  // 约束：a * b = c
endtypeclass

// 使用示例
provisos (Mul#(n, 2, m));  // m = 2n
```

### Log

编译时对数约束（向上取整）。

```bluespec
typeclass Log#(numeric type a, numeric type b);
  // 约束：2^b = a 或 2^(b-1) < a ≤ 2^b
endtypeclass

// 使用示例
provisos (Log#(n, logn));  // logn = ceil(log2(n))
```

### TExp

编译时指数（类型函数，不是 proviso 类；无 `Exp` 约束类）。

```bluespec
// TExp#(n) 是类型级函数：TExp#(n) = 2^n
// 使用示例
Vector#(TExp#(3), int) v;  // 8 个元素
```

### Min

编译时最小值约束。

```bluespec
typeclass Min#(numeric type a, numeric type b, numeric type c);
  // 约束：c = min(a, b)
endtypeclass

// 使用示例
provisos (Min#(n, m, k));  // k = min(n, m)
```

### Max

编译时最大值约束。

```bluespec
typeclass Max#(numeric type a, numeric type b, numeric type c);
  // 约束：c = max(a, b)
endtypeclass

// 使用示例
provisos (Max#(n, m, k));  // k = max(n, m)
```

### Alias

类型相等约束，强制两个类型参数相同。

```bluespec
typeclass Alias#(type a, type b);
  // 约束：a 和 b 是同一类型
endtypeclass

// 使用示例
module mkM#(t1 a, t2 b)(Empty) provisos (Alias#(t1, t2));  // 值参数绑定 t1、t2
  // t1 和 t2 必须是同一类型
endmodule
```
