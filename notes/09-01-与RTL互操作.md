# 与RTL互操作 - BVI

> BVI, Black Box Verilog Import - 是 BSV 中导入 RTL 模块的机制
> > 因为 bsc 直接只支持 Verilog 代码，所以其他的 HDL/HCL 都需要使用 Verilog 作为中转媒介，比如 VHDL 的导入需要 Verilog 包装器等等

**大致格式就是**：

```bluespec
import "BVI" <原始Verilog模块名> =
  module mk<BSV模块名> (<BSV接口类型>);

    // 时钟和复位（可选）
    default_clock <名称> (<Verilog时钟端口>);
    default_reset <名称> (<Verilog复位端口>);

    // 方法映射
    method <BSV方法名> (<参数列表>) en (<使能信号>) ready (<就绪信号>) = (EN_信号, RDY_信号);
    method <BSV方法名>() = <输出信号>;

    // 调度约束（告诉 BSV 编译器方法间的关系）
    schedule (<方法列表>) <约束类型> (<方法列表>);

  endmodule;
```

## MAC 模块示例 Verilog 导入

```verilog
// mymac.v
module mymac(
    input        clk,
    input        rst_b,
    input        EN,
    input  [15:0] a,
    input  [15:0] b,
    input        clear,
    input  [15:0] clear_value,
    output [15:0] out
);
    reg [15:0] out;

    always @(posedge clk or negedge rst_b)
        if (!rst_b)
            out <= 16'd0;
        else if (clear)
            out <= clear_value;
        else if (EN)
            out <= out + a * b;
endmodule
```

其中，我们的 BVI 包装器：

```bluespec
// MacBVI.bsv
package MacBVI;

// 定义 BSV 接口 给上层使用
interface MacIFC;
    // 乘加操作：out <= out + a * b
    method Action acc(Int#(16) aa, Int#(16) bb);
    // 复位操作：out <= value
    method Action reset_acc(Int#(16) value);
    // 读取当前结果
    method Int#(16) read_y();
endinterface

// 导入 Verilog 模块，`import "BVI"` 后面加原始的 Verilog 模块名
import "BVI" mymac =
    module mkMac (MacIFC);

        // 时钟复位映射
        default_clock clk (clk);
        default_reset rst (rst_b);

        // acc 方法：对应 EN, a, b
        // ready(1) 表示永远就绪（因为 Verilog 模块没有 ready 输出）
        method acc(aa, bb) en (EN) ready (1) = (EN_acc, RDY_acc);

        // reset_acc 方法：对应 clear, clear_value
        // 没有 ready 子句 = always ready
        method reset_acc(value) en (clear) = (EN_reset_acc);

        // read_y 方法：读取 out 寄存器
        method read_y() = out;

        // ============================================================
        // 调度约束（告诉 BSV 编译器这些方法之间的关系）
        // ============================================================
        // read_y 必须在 reset_acc 之前（读旧值，写新值下周期才可见）
        schedule (read_y) SB (reset_acc);
        // read_y 必须在 acc 之前（读旧值）
        schedule (read_y) SB (acc);
        // acc 和 reset_acc 冲突（不能同时调用，会写同一个寄存器）
        schedule (acc) C (reset_acc);

    endmodule;

endpackage

// 使用：`MacIFC mac <- mkMac;`
```

编译时指定 Verilog 文件目录：

```bash
# bsc 会按以下顺序查找：
# 1. 当前目录
# 2. -vsearch 指定的目录
# 3. $BLUESPECDIR/Libraries

bsc -verilog -vsearch ./rtl -vsearch ./ip -g mkTest Test.bsv
```

## FFT 模块示例 VHDL 导入

假设源文件：

```vhdl
-- my_fft.vhd
entity my_fft is
    port (
        clk     : in  std_logic;
        rst     : in  std_logic;
        start   : in  std_logic;
        data_in : in  std_logic_vector(15 downto 0);
        data_out: out std_logic_vector(31 downto 0);
        done    : out std_logic
    );
end entity;
```

创建包装器：

```verilog
// my_fft_wrapper.v
module my_fft_wrapper(
    input        clk,
    input        rst,
    input        start,
    input  [15:0] data_in,
    output [31:0] data_out,
    output        done
);
    // 实例化 VHDL 组件（工具会处理映射）
    my_fft u_my_fft (
        .clk(clk),
        .rst(rst),
        .start(start),
        .data_in(data_in),
        .data_out(data_out),
        .done(done)
    );
endmodule
```

之后就和上面一致了，其中，BVI 只找到 Verilog 这一层，到了 iverilog/vcs/quartus 这一步才会指定 VHDL 模块的路径，让它们读，而非 BSC 自己去读...
