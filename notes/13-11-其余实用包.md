# 标准库用法 (十)：其余实用包

> 可跑：`execs/13-11-01-Misc`。本篇收尾若干结构/工具包，配合 13-01 总目录看。

## CompletionBuffer（重排序缓冲：乱序完成、顺序流出）

```bsv
import CompletionBuffer::*; import GetPut::*;
CompletionBuffer#(8, Bit#(8)) cb <- mkCompletionBuffer;   // 8 个槽，元素 Bit#(8)
CBToken#(8) tok <- cb.reserve.get;             // ① 按序预订一个槽，拿 token
cb.complete.put(tuple2(tok, value));            // ② 任意顺序回填(乱序完成)
let v <- cb.drain.get;                          // ③ 严格按预订顺序流出
```
经典用途：多周期/可变延迟的执行单元乱序返回，但要按发射顺序提交。

## Once（封装一个只执行一次的 Action）

```bsv
import Once::*;
Once o <- mkOnce(action ... endaction);
rule r; o.start; endrule    // start 带 when ready：内部只放行一次；o.clear 复位可再来
```
> 坑：`start` 有隐式条件，**别在 seq 里连调多次**(第 2 次永远阻塞→死锁)，用一条 rule 让它自己只跑一次。

## 计数 1 的个数

```bsv
UInt#(4) n = countOnes(8'hB3);  // 内建(Prelude)，返回 UInt#(TLog#(n+1))；PopCount 包另有 popCountTree/popCountWallace
```

## 其它结构/工具包（配 13-01 速查）

| 包 | 一句话 |
|:---:|:---:|
| `Arbiter` | 轮转仲裁器 `mkArbiter`，N 个 client 抢 1 个资源，`grant_id` 给胜者 |
| `MIMO` | 多入多出队列，一拍 enq/deq 任意个数（变长打包） |
| `Gearbox` | 位宽/速率转换 FIFO（如 32→128 跨时钟域聚合） |
| `BitonicSort` | 组合双调排序网络，导出 `sortLe(le, vec)` |
| `EdgeDetect` | 边沿检测 |
| `TieOff` / `DummyDriver` | 给未用接口接默认值/空驱动 |
| `UniqueWrappers` | 把可复用组合函数包成共享硬件实例 |
