# 标准库用法 (七)：数学 FixedPoint / Complex / Real

> 可跑：`execs/13-08-01-Math`。

## FixedPoint（有符号定点 `FixedPoint#(isize, fsize)`）

```bsv
import FixedPoint::*;
FixedPoint#(4,8) x = fromRational(7, 8);   // 0.875；也有 fromInt/fromUInt/fromReal
FixedPoint#(4,8) y = fromRational(1, 2);   // 0.5
let z = x + y;        // +,-,* 保持定点(same type)；* 内部全精度后截断舍入
let p = x * y;        // 0.4375
fxptWrite(3, z);      // 打印小数 3 位(截断)
// 全精度(可不同位宽)：fxptMult/fxptAdd/fxptSub/fxptQuot
// 缩放：fxptTruncate/fxptSignExtend/fxptTruncateRoundSat(rmode,smode,x)；epsilon() 是最小量 2^-f
```

## Complex（`Complex#(t)`，t 为元素类型）

```bsv
import Complex::*;
Complex#(Int#(8)) a = cmplx(2, 3);   // 2+3i
Complex#(Int#(8)) b = cmplx(1, -1);  // 1-1i
let c = a * b;                        // 全复乘(4 乘法器)：5+1i
c.rel;  c.img;                        // 实/虚部
cmplxConj(a);  cmplxSwap(a);  cmplxMap(truncate, a);
```
