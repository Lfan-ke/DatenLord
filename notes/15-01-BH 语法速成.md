# BH 语法速成

> BH（`.bs`）与 BSV（`.bsv`）是**同一编译器 bsc 的两种语法**，编译流程、类库、语义完全一致，只是写法像 Haskell。可混用。
> 关键速记：**寄存器写 `:=`**、**规则 `when … ==>`**、**类型签名 `::`**、**provisos 是前置上下文 `(…) =>`**、**数值类型用并置 `Bit 8`**（不是 `Bit#(8)`）。

## 文件结构 & 布局

```haskell
package Foo (Counter(..), mkUpCounter) where   -- 无 endpackage；导出列表在 () 里
import FIFO                                      -- 不写 ::* ；可 import qualified M
import Vector
-- 顶层定义...
```

- 导出：`Name` 仅导出类型本身，`Name(..)` 连同其构造子/字段。
- **布局(offside 缩进规则)**：`where/let/do/of/module/interface/rules/action` 后是 `{ 项; 项 }` 列表；**缩进对齐可省略 `{}` 和 `;`**（更深=续行，同级=新项，更浅=闭合）。也可显式写 `{ ; }`。

## 词法 / 注释

- `--` 行注释（后接非符号字符）、`{- … -}` 可嵌套块注释、`{-# … #-}` pragma。
- 小写开头=变量/字段/类型变量；大写开头=包名/类型名/构造子。`_` 是通配。

## 类型 & 数据

```haskell
type Byte = Bit 8                         -- 类型别名
data Color = Red | Green | Blue           -- 枚举
             deriving (Eq, Bits, Bounded)
data Maybe a = Nothing | Just a            -- 多态 tagged union
struct Coord = { x :: Int; y :: Int }      -- 结构体（记录）
              deriving (Bits)
-- 数值(size)类型并置：Bit 16 / UInt 32；约束类 Add/Max/Log；valueOf t :: Integer
-- Bits 类：pack :: a -> Bit n ; unpack :: Bit n -> a
```

## 函数 / 控制

```haskell
-- 签名 + 方程（可多子句、可加 when 守卫）
gcd' :: Integer -> Integer -> Integer
gcd' a 0 = a
gcd' a b = gcd' b (a `mod` b)

sq = \x -> x * x                           -- lambda
let z = x + 1 in z * 2                     -- let..in（do/module 内 let 无 in）
if c then e1 else e2                        -- if 是表达式
case m of                                   -- case
   Just x  -> x
   Nothing -> 0
f $ g x                                     -- $ = 低优先级应用，等价 f (g x)
x `max` y                                   -- 反引号中缀
```

## 一个完整 BH 模块（示例 15-01-01）

```haskell
package Counter (Counter(..), mkUpCounter) where
interface Counter n =
    value :: Bit n
    inc   :: Action
    clear :: Action
mkUpCounter :: (IsModule m c) => m (Counter 8)
mkUpCounter = module
    cnt :: Reg (Bit 8)
    cnt <- mkReg 0
    rules
      "wrap": when (cnt == maxBound) ==> cnt := 0
    interface
      value = cnt
      inc   = cnt := cnt + 1          -- 寄存器写用 :=
      clear = cnt := 0
```

## BH ↔ BSV 对照（最常踩的点）

| 概念 | BH（Classic, `.bs`） | BSV（`.bsv`） |
|:---:|:---:|:---:|
| 包 | `package P (...) where` | `package P; … endpackage` |
| import | `import M` / `import qualified M` | `import M::*;` |
| 类型签名 | `x :: T`（处处） | `T x;` / `function T f(...)` |
| provisos | 前置 `(Bits a sa) => …` | 后置 `provisos (Bits#(a,sa))` |
| 数值类型 | `Bit 16`、`UInt 32`（并置） | `Bit#(16)`、`UInt#(32)` |
| 模块签名 | `mkX :: … -> Module (Ifc)` | `module mkX(...)(Ifc) provisos(...);` |
| 模块结尾 | 布局/`}`（无 endmodule） | `… endmodule` |
| 实例化 | `r :: Reg Int <- mkReg 0` | `Reg#(Int) r <- mkReg(0);` |
| **寄存器写** | **`r := v`** | **`r <= v`** |
| 寄存器读 | 裸 `r`（自动 `._read`） | 同 |
| 接口声明 | `interface I a = m1 :: …; m2 :: …` | `interface I#(type a); method …; endinterface` |
| 构造接口值 | `interface I {…}` / `interface (e1,e2)` | `return interface I; …` |
| **规则** | **`"名": when (c) ==> body`** | `rule 名 (c); body endrule` |
| 隐式条件 | 方法 `= expr when cond` | `method … if (cond);` |
| action 块 | `action { …; … }` / 布局 | `action … endaction` |
| 函数 | `f x y = e`（+ `f :: …`） | `function T f(...); … endfunction` |
| 条件/case | `if…then…else` / `case…of` | `if(...)` / `case(...) … endcase` |
| lambda | `\x -> e` | （无直接对应） |
| 注释 | `--`、`{- -}` | `//`、`/* */` |

> 详见：模块/接口/寄存器 → 15-02；规则/Action → 15-03。
> 可跑示例：`execs/15-01-01-BhCounter`（BH 计数器）、`execs/15-01-02-BhVsBsv`（同一计数器 BH 与 BSV 两版，都编译出 `.v`）。
