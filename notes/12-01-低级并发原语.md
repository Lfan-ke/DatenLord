# 低级并发原语

<!-- LEC13 低级原语 -->

| 原语 | 顺序约束 | 同周期可见 | 多写 | 用途 |
|:------:|:---------:|:-----------:|:------:|:------:|
| `mkReg` | `read < write` | ❌ 否 | 单一 | 普通状态寄存器 |
| `mkRegU` | `read < write` | ❌ 否 | 单一 | 未初始化状态寄存器 |
| `mkCReg` | `p0 < p1 < p2...` | ✅ 是（高编号） | 多端口 | 高并发状态 |
| `mkRWire` | `wset < wget` | ✅ 是 | 单一（冲突） | 周期内通信 |
| `mkPulseWire` | `send < read` | ✅ 是 | 单一 | 脉冲通知 |
| `mkDWire` | `write < read` | ✅ 是 | 单一 | 组合连线（有默认值） |
| `mkBypassWire` | `write < read` | ✅ 是 | 单一 | 组合连线（无默认值） |

## 各原语详解

### mkReg - 普通寄存器

```bluespec
// 顺序约束: read < write
// 同周期不可见：写入的值下个周期才能读到
Reg#(Bit#(8)) cnt <- mkReg(0);   // 注意 reg 是保留字，不能做标识符

rule r;
    cnt <= cnt + 1;  // 读旧值，写新值（不同周期可见）
endrule
```

### mkRegU - 未初始化寄存器

```bluespec
// 顺序约束: read < write
// 无初始值，综合时节省面积
Reg#(Bit#(8)) cnt <- mkRegU;
```

### mkCReg - 并发寄存器

```bluespec
// 顺序约束: p0 < p1 < p2 < ...
// 多端口，高编号端口可读低编号端口的同周期写入
Reg#(Bit#(8)) creg[2] <- mkCReg(2, 0);

// 提交值=本周期被写的【最高编号端口】的值；低编号端口的写只是【前递】给更高编号端口的读
```

### mkRWire - 周期内线网

```bluespec
// 顺序约束: wset < wget
// 接口
interface RWire #(type t);
    method Action wset(t datain);   // 设置值
    method Maybe#(t) wget;          // 获取值（返回 Valid 或 Invalid）
endinterface

module mkRWire(RWire#(t));          // 原语
```

**使用示例**：

```bluespec
module mkExample(Empty);
    RWire#(Bit#(8)) rw <- mkRWire();

    // 规则A：写入值
    rule rA;
        rw.wset(42);
    endrule

    // 规则B：读取值（调度在 rA 之后）
    rule rB;
        case (rw.wget) matches
            tagged Valid .x: $display("got value: %0d", x);
            tagged Invalid: $display("no value this cycle");
        endcase
    endrule
endmodule
```

**特性**：
- 同周期内，后续规则可读到前面规则写入的值
- 多个 `wset` 会冲突（不能在同一周期多次写入）
- 返回 `Maybe#(t)` 类型（`Valid` 或 `Invalid`）

### mkPulseWire - 脉冲线网

```bluespec
// 顺序约束: send < read
// 接口
interface PulseWire;
    method Action send();   // 发送脉冲
    method Bool _read();    // 读取是否有脉冲
endinterface

module mkPulseWire(PulseWire);  // 原语
```

**使用示例**：

```bluespec
module mkExample(Empty);
    PulseWire pw <- mkPulseWire();

    // 规则A：发送脉冲
    rule rA (condition);
        pw.send();
    endrule

    // 规则B：检测脉冲（调度在 rA 之后）
    rule rB;
        if (pw._read())
            $display("pulse received");
    endrule
endmodule
```

**特性**：
- 无数据值，仅传输脉冲
- 同周期内可见

### mkDWire - 默认值线网

```bluespec
// 顺序约束: write < read（与 mkReg 相反！）
// 接口
typedef Reg#(t) Wire#(type t);

module mkDWire #(t default) (Wire#(t));  // 原语
```

**使用示例**：

```bluespec
module mkExample(Empty);
    // mkDWire 有默认值，如果同周期未写入则使用默认值
    Wire#(Bit#(8)) dw <- mkDWire(0);

    // 写入
    rule r_write;
        dw <= 42;
    endrule

    // 读取（同周期可见写入的值）
    rule r_read;
        $display("value: %0d", dw);  // 如果 r_write 在同一周期且调度在前，则显示42
    endrule
endmodule
```

**特性**：
- 顺序约束与 `mkReg` **相反**：`write < read`
- 有默认值，未写入时返回默认值
- 同周期写入可见

### mkBypassWire - 旁路线网

```bluespec
// 顺序约束: write < read
// 与 mkDWire 类似，但无默认值
module mkBypassWire (Wire#(t));  // 无参数；写端 always_enabled（须每周期写），读端无隐式条件
```

## 顺序约束图解

```
mkReg:      read ──[下一周期]──> write
            (读旧值，写新值，不同周期)

mkRegU:     read ──[下一周期]──> write
            (与 mkReg 相同)

mkCReg:     p0 < p1 < p2 ...
            (同周期，高编号可读低编号写入)

mkRWire:    wset ──[同周期]──> wget
            (写入 → 读取，同一周期)

mkPulseWire: send ──[同周期]──> read
            (发送 → 读取，同一周期)

mkDWire:    write ──[同周期]──> read
            (与 mkReg 相反！写入 → 读取，同一周期)

mkBypassWire: write ──[同周期]──> read
            (与 mkDWire 相同，但无默认值)
```

## 使用场景推荐

| 原语 | 推荐使用场景 |
|:------:|:-------------:|
| `mkReg` | 绝大多数状态寄存器 |
| `mkRegU` | 综合优化，不需要初始值 |
| `mkCReg` | 多端口高并发状态（如寄存器文件） |
| `mkRWire` | 同一周期内规则间传递带数据的信息 |
| `mkPulseWire` | 同一周期内规则间发送脉冲信号 |
| `mkDWire` | 组合逻辑连线，有默认回退值 |
| `mkBypassWire` | 组合逻辑连线，无默认值 |

---

## 其他补充

> RWires must be used with great care! With all other primitives (including CRegs), functional correctness is typically preserved across arbitrary schedules. This is typically not true with RWires, which are only meaningful for intra-clock communication.

1. **RWires 的正确性依赖特定调度顺序**
2. **主要用于与外部 RTL 接口**
3. **不保证跨任意调度的功能正确性**
4. **使用前确保理解调度顺序的影响**
