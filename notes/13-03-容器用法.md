# 标准库用法 (二)：容器 Vector / List / ListN

> 可跑：`execs/13-03-01-Containers`。

## Vector（定长、可综合，元素0在低位）

```bsv
import Vector::*; import BuildVector::*;   // vec(...) 字面量在 BuildVector

Vector#(4, Bit#(8)) a = vec(1,2,3,4);          // 字面量
Vector#(4, Bit#(8)) b = replicate(10);          // 全填 10
Vector#(4, Bit#(8)) c = zipWith(\+ , a, b);     // 逐元素：[11,12,13,14]
Bit#(8) total = fold(\+ , c);                   // 折叠求和(平衡树 O(log n))
let d  = map( \* (2), a);                        // 映射
let r  = reverse(a);  let hit = elem(3, a);      // 反转 / 成员判断
let x  = a[2];        let a2 = update(a, 1, 99);  // 读(=) / 函数式写

// Vector of Reg —— 寄存器组（最常用）
Vector#(4, Reg#(Bit#(8))) rs <- replicateM(mkReg(0));
rs[1] <= 233;                                    // 元素是 Reg 才能 <=
Bit#(8) s = fold(\+ , readVReg(rs));             // readVReg 取出值再 fold
```

常用：`newVector replicate genWith` · `map zipWith fold(l/r) scanl mapAccumL` · `head last tail take drop append concat rotate` · `elem any all find findIndex countElem` · monad 版 `mapM/zipWithM/replicateM/genWithM`(实例化 N 份硬件)。

## List（编译期/elaboration，非可综合状态）

```bsv
import List::*;
List#(Integer) xs = upto(0, 9);          // [0..9]
List#(Integer) ys = List::map(square, xs);
// 用途：生成循环、配置表、编译期计算；计数参数 Integer 在第一个位置（take(n,xs)）
```

## ListN（定长 List，可 `Bits`）

```bsv
import ListN::*;
ListN#(4, Bit#(8)) v = ...;   // 顺序处理(head/tail/fold)首选；随机索引用 Vector
```
