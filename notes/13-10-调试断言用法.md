# 标准库用法 (九)：调试 Probe / 断言 Assert / 静态消息

> 可跑：`execs/13-10-01-Debug`。

## Probe（只写探针，专为看波形）

```bsv
import Probe::*;
Probe#(Bit#(8)) p <- mkProbe;
rule r; p <= someSignal; endrule    // 只能写；综合后波形里出现 p$PROBE，不影响调度/逻辑
```
比临时加 `Reg` 好：不参与逻辑、不被优化掉、不引入额外约束。

## Assert（断言，需 `-check-assert` 才生效）

```bsv
import Assert::*;
staticAssert(valueOf(n) > 0, "n must be > 0");   // 静态期(编译时)断言，失败即编译错
dynamicAssert(cond, "msg");                       // 运行期：cond 为假 → $error/$fatal（在某 rule 内）
continuousAssert(cond, "msg");                     // 每拍检查（内部建一条恒检查的 rule）
```
> 仿真要带 `bsc -sim -check-assert ...`，否则 dynamic/continuous 断言被忽略。

## 静态期消息 / 报错

```bsv
messageM("...");   // 细化期(编译时)打印一行，调参/调试 typeclass 很有用
errorM("...");     // 细化期直接报错中止（配合静态条件用）
warningM("...");
```
