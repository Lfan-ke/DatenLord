# BH 互操作（Verilog / C）

> 接 15-01~03。BSV 用 `import "BVI"`(09-01) / `import "BDPI"`(10-03) 做互操作；BH 的写法不同，本篇给**真跑通**的做法。

## 一、导入 Verilog —— `module verilog`（= BH 的 BVI）

```haskell
-- 语法：module verilog "模块名" [参数] "CLK" ["RST"] [args] { 方法=端口…; } [调度]
interface Counter =
    up     :: PrimAction        -- ★ Action 方法在此必须是 PrimAction（不是 Action）
    preset :: Bit 4 -> PrimAction
    value  :: Bit 4

vCount :: Module Counter
vCount = module verilog "count4" "CLK" "RST_N" {
    up     = "enable";          -- 使能端口
    preset = "inp" "set";       -- 输入端口 inp + 使能 set
    value  = "outp";            -- 输出端口
} [ value <> value, value < up, value < preset,
    up << up, preset << preset, up << preset ]
```

要点（源 `specs/doc/BH_ref_guide/BH_lang.tex §Interfacing to Verilog`，实例见 `Prelude.bs` 的 `vMkReg`）：

- **形如** `module verilog NAME [参数tuple] CLK [RST] [args] { … } [调度]`；无参数则省略参数位，直接跟时钟串。
- **Action 方法用 `PrimAction`**：类型以 `PrimAction` 结尾→所有端口是输入、最后一个是**使能**；否则最后一个是**输出**。
- **端口属性**(花括号内)：`{reg}`/`{const}`/`{unused}`/`{inhigh}`（inhigh=always-enabled 无线）。
- **调度算子**：`<>` 无冲突(CF)、`<` 顺序可组合(SB)、`<<` 受限顺序(SC) —— 即 BSV `schedule` 的对应。
- 规则里调用 `PrimAction` 方法要用 **`fromPrimAction`** 升为 `Action`：`when … ==> fromPrimAction c.up`。
- 多端口：`rd[3] = "raddr" "rdata"` 生成 `raddr_1/2/3`。

> 可跑：`execs/15-04-01-BhBvi` —— 真实 `count4.v` 经 `module verilog` 导入，iverilog 跑出 `count=12`（逻辑全在 Verilog 里）。

## 二、调用 C（DPI-C / BDPI）

BH 的 `.bs` **不支持** `import "BDPI"` 串语法（P0005）；裸 `foreign` 关键字是**底层原语**（内部 ABI：bluesim 生成的调用首参是位宽描述串 `c_add("32,32",3,4)`，且不为用户函数生成 C 原型）——它是给 Prelude/系统任务用的（如 `foreign $display :: PrimAction = "$display"`）。

**真正可用的用户级 C 导入**：用一个 **BSV 文件**写 `import "BDPI"`，BH `import` 该包调用（BSV/BH 同编译器，可互相 import）：

```bsv
// CImp.bsv —— 由 BSV 负责 BDPI 导入
package CImp;
import "BDPI" function Bit#(32) c_add(Bit#(32) a, Bit#(32) b);
endpackage
```

```haskell
-- UseC.bs —— BH 直接 import 并调用
package UseC (mkUseC) where
import CImp
mkUseC :: Module Empty
mkUseC = module
    rules
      "r": when True ==> action { $display "sum=%0d" (c_add 3 4); $finish 0 }
```

```bash
bsc -sim -u -g mkUseC ... UseC.bs
bsc -sim -e mkUseC ... -o sim cfns.c   # cfns.c: unsigned int c_add(unsigned int,unsigned int){return a+b;}
./sim   # → sum=7
```

> C 侧 ABI 与 10-03 的 BDPI 完全一致（窄返回直接 return，按位宽分桶到 unsigned char/int/long long）。
> 可跑：`execs/15-04-02-BhForeign`（`make run` → `sum=7`）。

## 三、BH 的综合/内联 pragma（= BSV 的 `(* synthesize *)`/`(* noinline *)`）

```haskell
{-# verilog mkFoo #-}                            -- 强制 mkFoo 生成独立 Verilog 模块（= (* synthesize *)）
{-# verilog mkFoo { noReady, alwaysEnabled } #-} -- 带属性（属性须用花括号；拼写是 noReady/alwaysEnabled）
{-# noinline cswap #-}                           -- 让函数生成独立硬件（= (* noinline *)）
```

## BH ↔ BSV 互操作对照

| | BH（`.bs`） | BSV（`.bsv`） |
|:---:|:---:|:---:|
| 导入 Verilog | `module verilog "M" CLK [RST] {…} [sched]` | `import "BVI" M = module … endmodule` |
| 黑盒 Action 方法 | `PrimAction`（调用用 `fromPrimAction`） | `method Action … enable(…)` |
| 调度 | `<>` / `<` / `<<` | `schedule … CF/SB/C …` |
| 调 C | BSV 写 `import "BDPI"`，BH `import` 调用 | `import "BDPI" function …` |
| 综合标记 | `{-# verilog mkX #-}` | `(* synthesize *)` |
| 禁内联 | `{-# noinline f #-}` | `(* noinline *)` |
| VHDL | 同 BSV：经 Verilog 套壳（见 09-01/execs 09-01-02） | Verilog 套壳实例化 VHDL |
